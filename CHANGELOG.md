# Changelog

## 0.1.0-beta.2 — 2026-10-22

First public beta of Hikō, an independent self-hosted drone logbook for Japan.

- DJI TXT import with keychain caching and header-only fallback, plus manual entry.
- Bilingual review, drawn pilot signatures, airframe totals, maps, and optional enrichment.
- PDF and Excel flight records in MLIT Form 1 format.
- Persistent non-root containers and documented backup/restore.
- Fictional public demo, sample exports, screenshots, and walkthrough.
- English/Japanese documentation, MIT license, privacy and security guidance.
- Automated app/demo checks, architecture-specific container verification, versioned images, and build attestations.

Beta limitations: one shared fleet per instance; hardware coverage is still being collected; Forms 2/3 and DIPS submissions are outside scope. See [compatibility](docs/compatibility.md).
