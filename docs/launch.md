## Reddit draft

**Title:** I built an open-source tool that turns DJI flight logs into Japan's MLIT flight-record format — looking for pilot feedback

I made Hikō to reduce the copying involved in keeping flight records for Japan. It imports supported DJI TXT logs, lets you review the details and sign, and exports bilingual PDF and Excel records in MLIT Form 1 format. Manual entry is also available.

It is a self-hosted public beta for a pilot or trusted fleet. The interface is mainly English. The demo uses fictional data, so you can try it without an account, API key, or uploading a personal flight log.

- Demo: https://eliemada.github.io/hiko/
- Code and setup: https://github.com/eliemada/hiko

It is an independent project, not an official MLIT or DJI service. Daily inspection and maintenance forms (Forms 2/3), permissions, and DIPS submissions are separate. Encrypted DJI logs need your own Open API key, and imported details still need your review.

I'd especially like feedback from people flying in Japan: does the exported record fit your workflow, and which aircraft/controller/app version should I test next? Please don't post personal logs, coordinates, serials, or signatures publicly.
