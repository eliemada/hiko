Hikō is an independent, self-hosted drone logbook for pilots flying in Japan. Import supported DJI TXT logs or record flights manually, review and sign, and export bilingual PDF/Excel flight records in MLIT Form 1 format.

Try the [fictional-data demo](https://eliemada.github.io/hiko/) or follow the [installation guide](https://github.com/eliemada/hiko/blob/main/docs/self-hosting.md).

This is a beta for one trusted fleet per instance. Aircraft/controller coverage is still being collected. Forms 2/3, permissions, and DIPS submissions are outside scope; pilots must verify exported records. Encrypted logs need your own DJI Open API key.

Release images target Linux AMD64 and ARM64. The workflow verifies startup, restart persistence, and stopped-volume backup/restore on both architectures before publishing. Images include SBOM and provenance metadata. Attached files include sample exports, Compose configuration, a production dependency inventory, and checksums.

For updates, back up the whole data volume and keep your `.env` private. Schema migrations apply automatically. See the [changelog](https://github.com/eliemada/hiko/blob/main/CHANGELOG.md) and [privacy notes](https://github.com/eliemada/hiko/blob/main/PRIVACY.md).
